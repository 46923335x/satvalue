Methodology

Returns represent the listed Select Sector SPDR ETF relative to BTC/USD on shared completed daily observations. Trailing returns are cumulative, not annualized. Summary metrics use the full available common history; volatility is annualized from daily changes using 252 observations per year. Fund holdings and industry allocations are issuer-published fund data, not index holdings, and are subject to change.
